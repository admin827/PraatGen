# ============================================================================

# Generated scripts target Praat 6.4.15 or newer. The floor is set by
# `To Pitch (filtered autocorrelation)`: 6.4.15 is the release that
# "distinguished between pitch ceiling (flat) and pitch top (curved ceiling)",
# which is the parameter set that command now takes.
#
# 6.4.15 is not published for download, so the floor is verified at 6.4.16:
# the 11-argument FAC call executes there [X].
#
# WHAT TO DO: see APPENDIX_F_UX_STANDARDS.txt §S15. A script using anything
# below emits a version check before doing any work. It WARNS and offers to
# continue. It never refuses.
#
# ============================================================================
# 1. SILENT NUMERICAL CHANGES — THE DANGEROUS CLASS
# ============================================================================
#
# These commands exist on both sides of the floor and RETURN DIFFERENT
# NUMBERS. No error, no missing command. A version check is the only warning
# the user will get.
#
#   6.4.39   PowerCepstrogram: Get CPPS...
#            "Calibrated cepstral peak prominence measurement."
#            CPPS values from before 6.4.39 are NOT comparable with values
#            from 6.4.39 onward. Any clinical or AVQI work reporting CPPS
#            must gate on this. This is the single most consequential entry
#            in this file.
#
#   6.4.47   Sound: To LPC
#            "now defaults to channel averaging" — a multi-channel input
#            yields a different LPC than it did before.
#
#   6.4.24   FormantPath sampling-frequency bug fix; Formant measurement bugs
#            repaired in the autocorrelation and robust methods. Formant
#            values before 6.4.24 may differ.
#
