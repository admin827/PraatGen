# Generated scripts target Praat 6.4.39 or newer.
#
# The floor is set by the cepstral measures. 6.4.39 is the FIRST build whose
# CPPS values match current ones. Measured, Maryn/AVQI parameter set:
#
#       6.4.14  18.615235
#       6.4.20  18.615235
#       6.4.24  17.244598      revision 1 of the tilt-line fit
#       6.4.30  17.244598
#   ->  6.4.39  18.994932      revision 2 — from here, current
#       6.4.46  18.994932
#       6.6.30  19.037906      +0.043 dB from the floor: negligible
#
# Below 6.4.39 a user is 1.75 dB away from what a current Praat reports on the
# same recording with the same settings. At or above it, they are within
# 0.05 dB. That is the boundary worth defending.
#
# NOT 6.4.24, which is where the FIRST of the two revisions landed. A script
# run on 6.4.24 still disagrees with current by 1.75 dB, so a floor there
# would declare "supported" a build whose numbers do not compare.
#
# NOT 6.4.15, the floor through v1.1, which was set on the belief that
# `To Pitch (filtered autocorrelation)` took a different parameter set below
# it. Measured, that is not so:
#
#     6.4.14   To Pitch (filtered autocorrelation): 1,2,...,15
#              -> "Command requires only 11 arguments, not the 15 given."
#     6.6.30   same call, same message
#
# Identical arity. The canonical 11-argument call runs on 6.4.14 and returns
# 149.999960 Hz where 6.6.30 returns 150.000009 Hz — the eighth significant
# figure, on a fixture chosen to be hostile (pitch top 350, where "top"
# low-passes from 175 Hz up and a flat "ceiling" would not). 6.4.15 renamed
# the concept and changed what the third argument means internally; it did not
# change the call or, measurably, the answer.
#
# WHAT TO DO: see APPENDIX_F_UX_STANDARDS.txt §S15. EVERY script emits a
# version check before doing any work, listing the specific things THAT script
# uses that the running Praat is below. It WARNS and offers to continue. It
# never refuses.

# ============================================================================
# 1. SILENT NUMERICAL CHANGES — THE DANGEROUS CLASS
# ============================================================================
#
# These commands exist on both sides of the boundary and RETURN DIFFERENT
# NUMBERS. No error, nothing missing. All figures below are measured on one
# fixture: 150 Hz + 450 Hz + 1750 Hz, 1 s, 44.1 kHz, every argument explicit.
#
#   CEPSTRAL MEASURES — TWO SEPARATE REVISIONS, AND THE EFFECT DEPENDS ON THE
#   TILT-LINE SETTINGS, NOT ON THE COMMAND.
#
#   `Get CPPS` with the Maryn/AVQI parameter set (APPENDIX_D §5B — straight
#   tilt line, robust fit, subtract tilt "no"):
#
#       6.4.14  18.615235
#       6.4.20  18.615235
#       6.4.24  17.244598      <- -1.371 dB
#       6.4.30  17.244598
#       6.4.39  18.994932      <- +1.750 dB
#       6.4.46  18.994932
#       6.6.30  19.037906
#
#   Same call with Praat's own dialog defaults (exponential-decay tilt line,
#   Robust slow, subtract tilt "yes"):
#
#       6.4.14  15.722079
#       6.4.24  12.474814      <- -3.247 dB
#       6.4.39  ERROR — see §3, "Robust slow"
#       6.6.30  14.035679
#
#   The mechanism is the tilt-line fit, not the cepstrum. At the 6.4.24
#   boundary, straight-line fits move by -0.01 to +0.41 dB while both
#   exponential-decay fits move by more than 3 dB. The raw cepstrum peak moves
#   0.04 dB across the same boundary; peak prominence moves 3.91 dB.
#
#   Both revisions are BELOW the floor, so a script running at or above 6.4.39
#   is clear of them. They stay documented because inherited scripts, archived
#   data and cross-lab comparisons all reach back past the floor.
#
#   CONSEQUENCE FOR THE VERSION CHECK: a CPPS entry must be conditioned on the
#   tilt line and fit method the script actually emits. A script using a
#   straight tilt line has different exposure from one using exponential decay,
#   and warning both identically is wrong in one direction or the other.
#
#   PRAAT'S RELEASE NOTES NAME ONLY 6.4.39 ("Calibrated cepstral peak
#   prominence measurement"). The 6.4.24 revision was announced as formant
#   fixes, with no mention of cepstral measures. It was found by running the
#   builds, not by reading. Treat the notes as a starting list, never as the
#   coverage claim.
#
#   6.4.24   To Pitch (filtered autocorrelation)
#            Mean F0 moves from 149.999960 to 150.000009 Hz on the fixture.
#            Real, and below any threshold that matters. Recorded so a later
#            pass does not rediscover it and over-react.
#
#   6.4.47   Sound: To LPC
#            "now defaults to channel averaging" — announced, NOT YET MEASURED.
#            Needs a multi-channel fixture and an LPC-native query.
