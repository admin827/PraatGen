# ============================================================================
# THE FLOOR: PRAAT 6.4.15
# ============================================================================
#
# Generated scripts target Praat 6.4.15 or newer. The floor is set by
# `To Pitch (filtered autocorrelation)`, which PraatGen routes to for voice
# work: 6.4.15 is the release that distinguished "pitch top" from "pitch
# ceiling", which is the parameter set the command now takes.
#
# 6.4.15 itself is not published for download, so the floor is verified at
# 6.4.16, one patch above: the 11-argument FAC call executes there.
#
#   To Pitch (filtered autocorrelation): 0.0, 50, 800, 15, "no",
#       ... 0.03, 0.09, 0.5, 0.055, 0.35, 0.14        -> OK at 6.4.16
#
# WHAT TO DO ABOUT IT: see APPENDIX_F_UX_STANDARDS.txt §S11. A script that
# uses anything listed below emits a version check before it does any work.
# The check WARNS and offers to continue; it does not refuse.
#

# ============================================================================
# COVERAGE — READ THIS BEFORE TRUSTING AN ABSENCE
# ============================================================================

# This file is NOT a complete map of version requirements. It records what has
# been executed against both builds, which is a small fraction of the command
# set. A command absent from this file has an UNKNOWN minimum version — it has
# not been shown safe at the floor, only untested.
#
# The full determination is a version sweep across the 42 downloadable 6.4.x
# patch releases, probing every documented command by invoking it with excess
# arguments and reading Praat's reply:
#
#   «Command "X" not available for current selection»  -> absent
#   «Command requires only N arguments»                -> present, arity N

# entry at a time and states its own incompleteness rather than implying
